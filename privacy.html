Confidentialité

Version pilote. Soumission Express est actuellement une démonstration statique.

Données saisies dans la démo

Les soumissions, réglages d’entreprise et autres informations saisies dans l’application sont enregistrés uniquement dans le stockage local du navigateur utilisé. Cette version ne les transmet pas à une base de données cloud et n’offre pas de sauvegarde distante.

Sauvegarde et suppression

L’utilisateur peut exporter ses données au format JSON depuis les réglages, puis les réimporter plus tard. Il peut également supprimer les données locales depuis la même page.

Paiement

Aucun paiement automatique n’est déclenché par le site pilote. Lorsqu’un client accepte explicitement une offre commerciale, une facture PayPal peut être organisée séparément.

Prospection professionnelle

Les démarches commerciales doivent viser des contacts professionnels pertinents, respecter les exigences applicables à la juridiction concernée et fournir un mécanisme simple d’opposition.

Évolution du service

Si une version avec comptes utilisateurs, stockage cloud, analytics ou paiement automatisé est déployée, cette politique devra être mise à jour avant utilisation de ces fonctions.
